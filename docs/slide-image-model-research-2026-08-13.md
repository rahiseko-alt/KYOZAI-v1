# KYOZAI スライド画像モデル調査報告書

- 調査日: 2026-08-13
- 対象: KYOZAI Slide / 将来のKYOZAI APP
- 範囲: モデル、費用、速度、品質、検証方法の調査のみ
- 実装: 行わない

## 1. 結論

現行KYOZAI工程を変えない場合、暫定第一候補は **Gemini 3.1 Flash Image、1K、16:9、Standard API** とする。

ただし、公式仕様だけで日本語教材スライドの実品質は決められない。最終採用は、本報告書の同条件A/B試験で次の3候補を比較して決める。

1. `gemini-3.1-flash-image` 1K
2. `gemini-3.1-flash-lite-image` 1K
3. `gpt-image-2` Medium、約1Kの16:9

`GPT Image 2 Low`は最安だが、現行KYOZAIの完成スライド生成を本番標準にする候補からは外す。文字をコードで後合成する別方式なら有力だが、それは現行Skillと工程を変えるため、今回の調査対象外とする。

## 2. 現行工程の事実

現行Skillは次の方式である。

- 内容、表示文言、講師台本、レイアウトを先に確定する。
- Codex組み込み`image_gen`へ、表示する日本語を含む完成スライドのプロンプトを渡す。
- 1スライドずつ完成PNGを生成する。
- 日本語の誤字、余計な文字、切れ、重なりを画像検証し、不合格ページだけ再生成する。

根拠は`.agents/skills/kyozai-slide/SKILL.md`の65行、281行、290行、296行、306行付近にある。

したがって、現在の「文字を焼き込む」は、正確な文字をプログラムで後合成する意味ではない。画像AIが文字まで描き、その結果をラスター画像として固定する意味である。表示項目を細かく決めることは構成の安定に効くが、文字の完全一致を保証しない。

## 3. 候補比較

20枚、通常API、入力料金を除く画像出力料金の概算は次の通り。

| 候補 | 設定 | 20枚概算 | KYOZAIでの位置づけ |
|---|---|---:|---|
| Gemini 3.1 Flash Image | 1K、16:9 | $1.34 | 暫定第一候補 |
| Gemini 3.1 Flash Lite Image | 1K、16:9 | $0.672 | 速度・費用対照候補 |
| GPT Image 2 | Medium、1536x1024相当 | $0.82 | 品質対照候補 |
| GPT Image 2 | Low、1536x1024相当 | $0.10 | 完成スライド標準から除外 |

### Gemini 3.1 Flash Image

- Googleは、速度・高スループット向けで、品質・一貫性・国際化テキスト描画を改善したモデルとしている。
- 1Kの16:9は`1376x768`。KYOZAIの最終サイズへ正規化できる。
- 1Kは1枚`$0.067`、20枚`$1.34`。
- Liteとの差額は20枚で`$0.668`。再修正の人件費と見込み客体験を考えると、品質改善が確認できれば十分許容できる。

### Gemini 3.1 Flash Lite Image

- 1K限定だが16:9に対応する。
- 公式の目標はエンドツーエンド2秒未満。これは1画像のモデル目標であり、20枚全体が2秒で終わる保証ではない。
- 1枚`$0.0336`、20枚`$0.672`。
- Groundingなし、参照画像なし、複雑な写実画像なしという条件には合う。
- ただしKYOZAIでは、背景ではなく日本語を含む完成スライドを生成する。安さだけで標準採用せず、文字完全一致率と再生成率で判断する。

### GPT Image 2

- 任意に近い解像度を指定でき、16:9の直接生成に向く。
- Lowは高速ドラフト向けと公式に位置づけられている。
- 公式にも、正確な文字配置、構造的な構図、ブランド要素の一貫性には失敗し得ると記載されている。
- Mediumは比較対象に残す。OpenAIの既存運用基盤を再利用できる点は有利だが、日本語教材の優劣は実測が必要。

## 4. 速度と同時生成

KYOZAIの20ページは、ページごとに内容とプロンプトが異なる。OpenAIの複数画像指定を使っても、同じプロンプトの候補生成とは異なり、ページ別の生成・検証・再試行単位は必要である。

通常経路は3並列を基準に比較する。全20件を無制限並列にすると、アカウント別のRPM/IPM、429、再試行の影響を受け、比較条件も崩れる。

Gemini Batchは安いが、公式に完了まで最大24時間としている。見込み客がその場で待つ体験版の通常経路には採用しない。夜間生成や再生成バックログだけが候補となる。

## 5. 同条件A/B試験

### 固定条件

- 参照画像なし
- Google Search Groundingなし
- 16:9
- 約1K
- 1ページ1リクエスト
- 同じdeck spec
- 同じ表示文言
- 同じ要素数、色、余白、配置制約
- 同じ禁止事項
- プロバイダー固有の品質向上文言を追加しない
- 通常API
- 同時数3
- 失敗時は同一プロンプトで1回だけ再生成

### 試験母集団

KYOZAIの実用途から20種類を選び、各モデルで5回ずつ生成する。1モデル100枚、3モデル合計300枚とする。

- 表紙 2種類
- 箇条書き 3種類
- 手順 3種類
- 比較 3種類
- 因果・フロー 3種類
- 数値・KPI 2種類
- 注意喚起 2種類
- まとめ・行動 2種類

概算画像出力費用は、Flash`$6.70`、Lite`$3.36`、GPT Image 2 Medium`$4.10`、合計`$14.16`。入力料金は別途だが小さい。失敗修正の方向を誤るコストより十分小さい。

### ハード合格条件

1ページでも次に該当すれば、その出力は不合格とする。

- 指定日本語の誤字、欠落、置換
- 指示していない文字の追加
- 必須要素の欠落
- 要素の重なり、切れ、画面外配置
- 小さすぎて投影・スマホ表示で読めない文字
- 指定した関係、順序、比較方向の誤り
- ロゴ、透かし、不要な写真調背景の混入

見た目の好みで、文字や構造の不合格を相殺しない。

### 記録指標

- 初回合格率
- 1回再生成後の合格率
- 20ページ教材としての全ページ合格率
- 文字エラー率
- 余計な文字の発生率
- 構図・要素欠落率
- P50 / P95の1枚生成時間
- 3並列での20枚完了時間
- 1教材あたり実費
- 合格1枚あたり実費
- 人手確認時間

## 6. 採用ルール

平均点ではなく、次の順で選ぶ。

1. ハード合格条件を満たす率が最も高い。
2. 1回再生成後の20ページ全体合格率が最も高い。
3. 同等品質ならP95完了時間が短い。
4. 品質と時間が同等なら安い。

暫定第一候補のGemini 3.1 Flash Imageが、Liteに対して文字・構造合格率を改善しない場合はLiteへ下げる。GPT Image 2 Mediumが両Gemini候補より教材全体の合格率で優れる場合はOpenAIへ戻す。

## 7. 現時点の判断

本サービスの価値は、最安生成ではなく「資料を入れたら、そのまま使える完成品が返る」ことである。20枚あたり数十セントの差より、日本語誤字や構図崩れによる再修正回数の方が顧客体験と原価に効く。

よって、調査段階の標準候補はGemini 3.1 Flash Imageとし、Flash Liteを速度・費用対照、GPT Image 2 Mediumを品質対照に置く。実装には進まず、同条件A/B試験の承認後に実測だけを行う。
